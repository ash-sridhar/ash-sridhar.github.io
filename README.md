# Ashwath Sridhar portfolio

Static site, no build step. Commit these files to the root of the repository and GitHub Pages serves them.

Where to edit
- `index.html`: hero, About, experience, skills, career goals, contact (most text lives here)
- `content.js`: project cards, case-study write-ups, and the Discovery project text and images
- `script.js`: behavior (project order, intro animation, background traces)
- `styles.css`: colors and layout
- `Ashwath_Sridhar_Resume.pdf`: replace this file (keep the name) to update the resume

Add `?intro` to the URL to replay the power-on intro; it otherwise plays once per browser session.

Features: keychain inspector (hotspot list in `script.js`), Layers viewer (bottom-left), project dialogs that zoom from the card, press P or use the footer button to power-cycle the board.
