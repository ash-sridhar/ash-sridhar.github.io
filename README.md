# Ashwath Sridhar portfolio

Static site (no build step). Deploy by committing these files to the root of `ash-sridhar.github.io` on `main`.

- `index.html`: page content (hero results table, experience, skills, about, contact)
- `content.js`: project and Discovery case-study text and galleries
- `styles.css`, `script.js`: styling and the case-study dialogs
